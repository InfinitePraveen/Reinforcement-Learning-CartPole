# Contributing

Thanks for your interest in contributing to this CartPole reinforcement learning project.

## Simple contribution flow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Test the notebooks or Flask application locally.
5. Update `CHANGELOG.md` when the change is user-facing.
6. Open a pull request with a clear description.

## Good contribution ideas

- Improve the Q-learning explanation.
- Add a small evaluation experiment.
- Improve the Flask visualization.
- Fix documentation or compatibility issues.
- Improve CPU-friendly training settings.

Please keep the repository simple. Avoid adding a `src/` package, preprocessing modules, or unnecessary utility scripts.
